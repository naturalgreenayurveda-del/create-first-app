# Flutter App Blueprint

## Architecture

- Feature-first modular structure.
- State management with Riverpod or Bloc.
- Repository pattern for API integration.

## Feature modules

- `auth`: login/signup + onboarding preferences.
- `upload`: camera/gallery/video upload with framing guides.
- `analysis`: progress view while AI job is running.
- `recommendations`: categorized style suggestions with explanations.
- `shopping`: product listing, filtering, and buy-link redirection.
- `profile`: history, saved looks, and preferences.

## UX principles

- Fast feedback during processing.
- Explainable AI outputs (“why this suggestion”).
- Frictionless route from recommendation to purchase.
